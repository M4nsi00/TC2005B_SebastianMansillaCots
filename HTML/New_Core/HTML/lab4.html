Preguntas

1. ¿Qué diferencia y semejanzas hay entre Java y JavaScript?

Java por un lado es un lenguaje compilado, en otras palabras es un lenguaje que se compila y corre en terminal similar a como funciona C++ o Python. Por otro lado JavaScript es un lenguaje interpretado, similar a html ambos corren desde el navegador.
Otra diferencia es su tipado, Java tiene un tipado fuerte y estático, mientras que JavaScript tiene tipado más flexible y dinámico.
Java tiene controles estrictos de seguridad y gestión de memoria, mientras que JavaScript al correr en navegador, es más suseptible a vulnerabilidades.

2. ¿Qué métodos tiene el objeto Date? (Minimo 5)

  • Date.now(), regresa los milisegundos transcurridos que han pasado desde el 1 de enero de 1970.
  • Date.parse(fecha), toma una fecha en inglés y regresa los milisegundos que han pasado desde el 1 de enero de 1970 hasta ese punto.
  • dateObj.getHours(), retorna un numero entre 0 y 23 representando la hora de la fecha dada de acuerdo a la hora local, funciona similar getFullYear(), getMinutes() o getSeconds().
  • getTimezoneOffset(fecha), regresa la diferencia en minutos entre la zona horaria de esa fecha con el horario UTC.
  • setDate(), cambia el dia del mes de una fecha dada.

3. ¿Qué métodos tienen los arreglos? (Minimo 5)

  • Array.from(x,y,z), crea un arreglo de una instancia iterable o similar.
  • Array.isArray(X), método estatico que determina si un valor es o no un arreglo, regresa true/false.
  • Array.findIndex(X), regresa el indice del primer elemento que cumpla con lo establecido dentro de la función, en caso que no sea así regresa un -1
  • Array.flat(), funcion que unifica sub arreglos de un elemnto hasta llegar a un subnivel especificado.
  • Array.concat(), fuciona dos o más arreglos, ESTE MÉTODO NO MODIFICA LOS ARREGLOS ORIGINALES solo los une en un nuevo arreglo.

4. ¿Cómo se declara una variable con alcance local dentro de una función?

Si se quiere tener una variable local se tiene que declarar dentro de algun bloque o funcion con la clave let o tambien se puede usar const

5. ¿Qué implementaciones tiene utilizar variables globales dentro de funciones?

Como estas variables son accesibles por medio de la consola en cualquier navegador, los usuarios pueden cambiar el valor de estas mismas con mucha facilidad, es por esto que se recomienda usar variables locales usando let en caso de requerrirlas o si son valores constantes definirlos como const. Otros problemas, son que las variables globales siempre viven en el sistema, entonces tener varias acumuladas no es bueno para disminuir el uso de memoria. Por último si se usan variables con nombres similares es posible que se confundan entre si.
